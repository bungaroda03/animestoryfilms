# Anime Story Films

A fiction film-story blog. Watch the clip, read the real story.

Each film is a serial: a short video clip on top, the full story in
written English below, ending on a cliffhanger. New episodes are added
as new pages — no comic panels, video + written story only.

## Films

- **Ember Blade** — retro 90s anime, feudal Japan. Ryu, 19, the last
  fire-sword swordsman, vs Kaito, the armored warlord.
- **I Married a Stranger for $100,000** — romance, Maya and Noah,
  a $100,000 contract marriage.
- **Restoring a 1969 Mustang** — cinematic ASMR restoration, a 1969
  Mustang abandoned for 30 years.

## Tech

Astro static site, deployed to GitHub Pages from the `main` branch,
custom domain `animestoryfilms.xyz`.

```bash
npm install
npm run dev
npm run build
```

Pushing to `main` triggers the GitHub Actions deploy workflow
(`.github/workflows/deploy.yml`).
